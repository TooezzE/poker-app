# Покер-трекер для домашних игр

## О проекте
Веб-приложение (PWA) для ведения домашней игры в покер. Открывается на iPhone:
Safari → «Поделиться» → «На экран Домой». Публиковать в App Store не планируется.

## Что должно уметь приложение
- Задавать список игроков.
- Настраивать игру: стоимость входа (бай-ин) и стартовый стек, стоимость ребая,
  стартовые малый и большой блайнды.
- Обновлять список игроков по ходу игры: кто выбыл, кто сделал ребай и т. д.
- Считать общий банк (все бай-ины и ребаи) для победителя.

- Таймер уровней блайндов: рост ×1,5 с округлением до круглых чисел,
  которые делятся на самую мелкую фишку (у меня фишки 5, 10, 25, 50, 100, 500),
  пауза, ручное переключение уровня вперёд/назад.
- Лимит ребаев (один на выбор): по количеству на игрока, по игровому времени
  или пока большой блайнд меньше порога.
- Ребай — только после вылета: «Выбыл» → игрок в секции выбывших → «Ребай».
  Игра не завершается сама: когда остался один, появляется «Завершить игру».
  Завершение окончательное (вернуться к игре нельзя). На экране итогов —
  «Обзор игры»: статистика и история вылетов/ребаев/входов с блайндами.
- История игр: каждая завершённая игра сохраняется (игра «без победителя» — нет).
  Кнопка «История» на главном экране → список игр → тот же «Обзор игры»;
  игру можно удалить из истории.

## Решения, которые уже приняты
- PWA, а не Telegram Mini App: работает офлайн и не зависит от Telegram.
- Бэкенда нет: все данные хранятся на телефоне.
- Стек: Vite + React + TypeScript.
- Хранение данных: Zustand с `persist` (localStorage).
- PWA: `vite-plugin-pwa` (манифест, иконка, service worker для офлайна).
- Стили: Tailwind CSS.
- Хостинг: GitHub Pages (запасной вариант — Netlify).

## Как писать код
- Игровая логика (банк, ребаи, выбывания) — чистые функции в `src/game/`,
  отдельно от интерфейса и с тестами. Так её можно будет перенести куда угодно.
- Экраны только показывают данные и вызывают действия стора
  («добавить ребай», «игрок выбыл»). Не класть игровую логику в `useEffect`.
- Время (например, для таймера) считать от сохранённой отметки старта,
  а не через `setInterval`: iOS приостанавливает свёрнутые веб-приложения.
- Сделать экспорт и импорт игры в JSON на случай смены телефона.
- Использовать Wake Lock, чтобы экран не гас за столом.
- Интерфейс в первую очередь под телефон: крупные кнопки, всё под большой палец.
