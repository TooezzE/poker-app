# Покер-трекер

PWA для домашней игры в покер: игроки, ребаи, вылеты, банк. Данные хранятся в телефоне.

**Открыть приложение:** https://tooezze.github.io/poker-app/
(на iPhone: Safari → «Поделиться» → «На экран Домой»).

## Публикация

Сайт обновляется сам: после `git push` в ветку `main` GitHub Actions прогоняет тесты,
собирает приложение и выкладывает его на GitHub Pages (см. `.github/workflows/deploy.yml`).
Ход публикации — на вкладке **Actions** репозитория. Если тесты или сборка упадут,
останется предыдущая версия сайта.

## Команды

Все команды запускаются в терминале из папки проекта.

| Команда | Что делает |
|---|---|
| `npm install` | Скачивает библиотеки (один раз после клонирования) |
| `npm run dev` | Запускает приложение на компьютере: http://localhost:5173/poker-app/ |
| `npm run dev:phone` | То же, но доступно с телефона в той же Wi-Fi-сети (адрес — в строке `Network`) |
| `npm test` | Запускает тесты игровой логики |
| `npm run lint` | Проверяет код на типичные ошибки |
| `npm run build` | Собирает готовый сайт в папку `dist/` |
| `npm run preview` | Показывает собранный сайт из `dist/`: http://localhost:4173/poker-app/ |
| `npm run icons` | Пересоздаёт PNG-иконки из `public/icon.svg` |

Остановить запущенный сервер: `Ctrl + C` в терминале.

## Где что лежит

```
src/
  game/        игровая логика (чистые функции) и тесты к ней:
               game.ts — игроки, ребаи, банк, история; blinds.ts — шкала блайндов;
               clock.ts — таймер уровней; stats.ts — статистика для обзора;
               history.ts — история завершённых игр
  store/       хранилище Zustand: данные + действия, сохраняются в localStorage
  screens/     экраны: настройка, игра, итоги, обзор игры, история игр
  components/  кнопка, поле для числа, карточки игроков, таймер, каркас экрана
  hooks/       useNow — перерисовка раз в секунду, useWakeLock — экран не гаснет
  App.tsx      выбирает, какой экран показать
  format.ts    форматирование чисел и склонения
public/        иконки
vite.config.ts настройки сборки и PWA (манифест, service worker), адрес /poker-app/
.github/workflows/deploy.yml  автоматическая публикация на GitHub Pages
```
